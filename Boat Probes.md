# Boat Probes Script

The `Boat Probes` script is the primary means of floating the boat. It is used whenever the boat is the current boat being used by the player. The secondary means of adding buoyancy is the `Boat Align Normal` script. The way `Boat Probes` works, is by checking the height of the waves at certain points around the ship and then determining how much force should act on the hull in that region. There are 6 main properties that we can edit:

- `Center of Mass`: This determines whereabouts all your buoyancy points will be centrally located from. We only care about the Y value of this. If your boat floats too high in the water, increase this Y value. If too low, decrease it. 
- `Force Points`: These are the force points we mentioned in the first paragraph. All vanilla boats, and most modded boats, have 12 points located around the hull. The idea is to have quite a large amount of room front-back between the points, but very little side-to-side. Think of it from the top-down perspective, 3 points side by side in-front of the bow, 3 under the bow, 3 under the stern, and 3 behind the stern. Reference vanilla `Boat Probes` scripts for more information. 
- `Force Multiplier`: The best way to think of what this does is to compare two ships separate in size. We'll compare the Dhow to the Leopard. When moving about on the deck of the Dhow, the whole boat sways. However on the Leopard, it does not do so because it is so large. The smaller the ship, the smaller this number should be. Play around with it. Note: you cannot edit this value in-game.
- `Spatial Length`: A value somewhat representative of the width of the boat. In my experience changing this value does little. It supposedly affects what waves will move your boat, for example small little ripples shouldn't jossle you around.
- `Drag in water right`: This determines how strongly your ship resists lateral movement left/right. Generally, you want to keep this value at 3. However this value can be changed for more responsive turning and/or a more accurate side loading from the sails.
- `Drag in water forward`: The main drag value that we care about, this determines the maximum speed for the boat. Notably, it does not *directly* change the acceleration, which is mainly due to the `Rigidbody`'s mass. Typical values range from 0.03 to 0.001 depending on size. You'll need to do a lot of in-game testing. This value can be edited while the game is running (Unity Runtime Editor).

## Boat Align Normals Synchronising
Once you have set the values that you feel are right for the ship, it is important to replicate these in the `Boat Align Normals` script as closely as you can (they will be completely different values), as this will ensure when the player hops on the boat for the first time it doesn't start bouncing around while it switches between the physics systems. You will know when you have got the values correct when switching between boats looks seamless.
